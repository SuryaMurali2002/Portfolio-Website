# Surya Murali · Portfolio

React 19 + Vite + Tailwind v4. Deployed on Vercel.

```bash
npm install
npm run dev
```

Content lives in `src/data.js`; visual effects are in `src/effects.jsx` and `src/hooks.js`.

Dates in `src/data.js` are `start`/`end` (`"YYYY-MM"`); leave `end: null` for an ongoing role ("Present"). Durations are computed.

Hidden extras: `Ctrl/⌘ + K` or `/` opens a command palette (also in the mobile menu), and the Konami code (↑↑↓↓←→←→BA) turns on code rain in any theme. Printing the page gives a clean, resume-style layout.
